⚠️ IMPORTANT NOTES:
═══════════════════════════════════════════════════════════════════════════════

🔴 OOM (Out of Memory) Issues?
   ├─ Reduce batch_size: batch=8 → batch=4
   ├─ Reduce image size: imgsz=1280 → imgsz=768
   ├─ Use nano model: yolov8m.pt → yolov8n.pt
   └─ Reduce epochs: epochs=100 → epochs=50

🟡 Training Too Slow?
   ├─ Check GPU is being used: nvidia-smi
   ├─ Reduce image size or batch size
   ├─ Use smaller model (yolov8n)
   └─ Close other applications

🟢 Want Even Better Results?
   ├─ Collect more labeled data
   ├─ Train for 150-200 epochs
   ├─ Use yolov8l model (larger, slower)
   ├─ Increase image size to 1536
   └─ Higher learning rate exploration
