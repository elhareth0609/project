� HOW TO TRAIN ON KAGGLE (RECOMMENDED)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Upload Dataset
   1. Go to: https://kaggle.com
   2. Create → New Dataset
   3. Upload: dataset_combined/ folder
   (Or upload animals & humain separately)

STEP 2: Create Kaggle Notebook
   1. Create → New Notebook
   2. Select your uploaded dataset
   3. Click "+ Add input" and select your dataset

STEP 3: Enable GPU (IMPORTANT!)
   1. Click "Session" button (top right)
   2. Select "Accelerator" → "GPU" (T4)
   3. Notebook will restart with GPU enabled

STEP 4: Copy & Paste Training Code
   Copy code from: kaggle_yolo11_notebook.py
   
   OR paste this simple version:
   ─────────────────────────────────────────────────
   !pip install -q ultralytics
   from ultralytics import YOLO
   
   model = YOLO('yolo11m.pt')
   model.train(
       data='/kaggle/input/[your-dataset]/data.yaml',
       epochs=50,
       batch=16,
       device=0,
       project='/kaggle/working'
   )
   ─────────────────────────────────────────────────

STEP 5: Run Training
   • Click "Run" or press Ctrl+Enter
   • Wait 30-45 minutes for training
   • Check GPU usage in "Session" panel

STEP 6: Download Model
   • Find: best.pt in output
   • Download and use for predictions

Expected Time: 30-45 minutes
Expected mAP@50: 0.85-0.95 (85-95% accuracy)

⚠️ نصائح مهمة | Important Tips:
═══════════════════════════════════════════════════════════════════════════════

✅ ماذا تفعل إذا حصلت على OOM:
   • قلل batch_size: 8 → 4
   • قلل image size: 1280 → 768
   • استخدم yolov8n بدل yolov8m

✅ إذا كانت النتائج ممتازة:
   • استخدم yolov8l للدقة الأعلى
   • زيادة epochs إلى 200
   • جرب imgsz=1536

✅ للنتائج الأفضل:
   • جمع بيانات أكثر (500-1000 صورة إضافية)
   • تنويع البيانات (زوايا مختلفة، إضاءة)
   • تنظيف البيانات (إزالة الصور الرديئة)
